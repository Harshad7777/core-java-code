Q1.
int[] a = {1, 2, 3, 4};
int[] b = a;
b[2] = 99;
System.out.println(a[2] + a[3]);

b and a refer to the same array.

b[2] = 99 → a[2] = 99

a[3] = 4
✅ Output: 99 + 4 = 103
------------------------------------------
Q2.
int[][] arr = { {1, 2}, {3, 4, 5}, {6} };
System.out.println(arr[1][arr[1].length - 1]);

arr[1] = {3, 4, 5}, arr[1].length = 3


arr[1][3 - 1] = arr[1][2] = 5
✅ Output: 5

arr[1] = {3, 4, 5}
The element at index 2 in {3, 4, 5} is 5 (because indexing starts at 0).

✅ Therefore: arr[1][2] → 5
-----------------------------------------------
Q3.
int[] arr = {1, 3, 5, 7, 9};
for(int i = 0; i < arr.length; i += 2) {
    arr[i] = arr[i] * 2;
}
System.out.println(arr[2]);

Loop: i = 0, 2, 4

arr[0] = 1×2 = 2

arr[2] = 5×2 = 10

arr[4] = 9×2 = 18
✅ Output: 10

Q7.

int[] a = {10, 20, 30};
int[] b = a.clone();
b[0]++;
System.out.println(a[0] + " " + b[0]);

clone() creates a separate copy.

b[0]++ → b[0] = 11, a[0] = 10
✅ Output: 10 11

Q8.

int[] arr = {2, 4, 6, 8, 10};
int total = 0;
for(int i = 1; i < arr.length; i++) {
    total += arr[i] - arr[i - 1];
}
System.out.println(total);

Differences:
(4−2) + (6−4) + (8−6) + (10−8) = 2+2+2+2 = 8
✅ Output: 8

Q10.
int[] nums = {5, 10, 15, 20};
for(int i = 0; i < nums.length - 1; i++) {
    nums[i + 1] = nums[i] + nums[i + 1];
}
System.out.println(nums[3]);

Step by step:

i=0 → nums[1]=5+10=15 → [5,15,15,20]

i=1 → nums[2]=15+15=30 → [5,15,30,20]

i=2 → nums[3]=30+20=50 → [5,15,30,50]
✅ Output: 50
