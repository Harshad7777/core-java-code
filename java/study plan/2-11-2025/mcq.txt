package org.techhub;
class Demo{
    public static void main(String args[])
    {
        int var1 = 42;
        int var2 = ~var1;
        System.out.print(var1 + " " + var2);      
    } 
}

Dry Run:

~var1 = bitwise NOT → flips all bits
Formula: ~n = -(n + 1)
→ ~42 = -(42 + 1) = -43

🟩 Output: 42 -43

package org.techhub;
class Demo {
        	public static void main(String args[]) {
                    	int a = 3;
                    	int b = 6;
                    	int c = a | b;
                    	int d = a & b;
                    	System.out.println(c + "\t" + d);
        	}
}
Binary:

a = 3 → 011

b = 6 → 110

a | b = 111 → 7

a & b = 010 → 2

🟩 Output: 7 2

package org.techhub;
class Demo {
    public static void main(String args[]) 
    {        
         byte x = 64;
         int i;.
         byte y; 
         i = x << 2;
         y = (byte) (x << 2);
         System.out.print(i + "\t" + y);
    } }
Dry Run:

x << 2 → 64 * 2^2 = 256

i = 256

y = (byte)256 → 256 - 256 = 0 (because byte range = -128 to 127)

🟩 Output: 256 0
