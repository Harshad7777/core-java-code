MCQ

Q1.
int[] arr = {5, 10, 15, 20};
int sum = 0;
for(int i = 0; i < arr.length; i++) {
    sum += arr[i];
}
System.out.println(sum);

✅ Output: 50
Explanation: 5 + 10 + 15 + 20 = 50

Q2.
int[] arr = {2, 4, 6, 8};
System.out.println(arr[arr.length - 1]);

arr.length = 4

arr[arr.length - 1] = arr[3] = 8

✅ Output: 8

------------------------------------------------------
Q3.
int[] arr = {1, 2, 3, 4, 5};
System.out.println(arr[5]);

Index starts from 0, so valid indices are 0–4.

arr[5] is out of bounds ❌

❌ Runtime Error:
ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5

Q4.
int[] a = {10, 20, 30};
int[] b = a.clone();
b[1] = 99;
System.out.println(a[1]);


a.clone() creates a new array (deep copy for primitives).

Changing b[1] does not affect a[1].

✅ Output: 20

Q5.
char[] vowels = {'a', 'e', 'i', 'o', 'u'};
System.out.println(vowels[2]);

Index 2 → third element = 'i'

✅ Output: i

Q6.

Q8.
int[] arr = {10, 20, 30, 40, 50};
for(int i = arr.length - 1; i >= 0; i--) {
    System.out.print(arr[i] + " ");
}


Prints array in reverse order.

✅ Output:
50 40 30 20 10
