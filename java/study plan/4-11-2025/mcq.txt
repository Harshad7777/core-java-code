Q7.
for(int i = 0; i < 5; i--) {
    System.out.println(i);
}

i starts at 0 and decreases forever, condition i < 5 is always true.

❌ Result:
Infinite loop (prints decreasing numbers forever: 0, -1, -2, -3...)

Q9.
int i = 1;
do {
    if(i == 4) continue;
    System.out.print(i + " ");
    i++;
} while(i <= 5);

⚠ Problem:
When i == 4, continue skips the increment, so i stays 4 forever → infinite loop.

❌ Result:
Infinite loop (stuck at i = 4)
